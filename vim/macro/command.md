# Vimマクロ - コマンドリファレンス

## マクロが輝く3つの組み合わせ

| 組み合わせ | できること | awkとの違い |
|-----------|-----------|-----------|
| マクロ × `:g` | パターンに合う行だけに選択的に適用 | awkでも可能だがawkスクリプトを別途書く必要がある |
| マクロ × テキストオブジェクト | コードの構造（単語・括弧）を対象にした変換 | 正規表現では表現しにくい構造的な変換をVim内で完結できる |
| マクロ × レジスタ | 変換中に値を保存して別の場所で使う | awkでも可能だがawkスクリプトを別途書く必要がある |

---

## マクロの記録と実行

```vim
qa      " aレジスタにマクロ記録開始
q       " マクロ記録終了
@a      " aレジスタのマクロを実行
@@      " 直前に実行したマクロを再実行
10@a    " aレジスタのマクロを10回実行
qA      " aレジスタに追記モードで記録開始（大文字 = 追記）
```

---

## :g（グローバルコマンド）

```vim
:g/pattern/command          " patternに一致する行にcommandを実行
:g!/pattern/command         " patternに一致しない行にcommandを実行

" マクロとの組み合わせ
:g/^async def/normal @q     " 行頭が async def の行にマクロ@qを実行
:g/function/normal @a       " function を含む行にマクロ@aを実行
:g/^#/d                     " # で始まる行を削除（コマンドはdも使える）

" 範囲を指定して実行
:10,20g/pattern/normal @a   " 10〜20行目の中でパターン一致行にのみ実行
```

## テキストオブジェクト（マクロでよく使うもの）

```vim
" inner系（境界文字を含まない）
iw      " inner word（単語）
i"      " inner "（ダブルクォートの中身）
i'      " inner '（シングルクォートの中身）
i(      " inner (（カッコの中身）  ※ib でも同じ
i{      " inner {（波カッコの中身）※iB でも同じ
i[      " inner [（角カッコの中身）

" around系（境界文字を含む）
aw      " around word（前後スペース含む）
a"      " around "（クォート自体を含む）
a(      " around (（カッコ自体を含む）

" マクロでの使用例
yiw     " カーソル位置の単語をヤンク
ciw     " カーソル位置の単語を削除してInsertモードへ
yi"     " ダブルクォートの中身をヤンク
ci(     " カッコの中身を削除してInsertモードへ
```

---

## レジスタをマクロ内で使う

```vim
" 記録中にレジスタへヤンク
"ayw            " aレジスタに単語をヤンク
"ayt(           " aレジスタに(の手前までヤンク

" Insertモード中にレジスタの内容を貼り付け
<C-r>a          " aレジスタの内容を貼り付け
<C-r>"          " デフォルトレジスタの内容を貼り付け

" 実用パターン：関数名を取り出して別の行で使う
"ayt(           " 関数名をaレジスタへ
o               " 新しい行を開く
def test_<C-r>a     " def test_ + aレジスタの内容
```

---

## 並列実行（エラーに強い方法）

```vim
" ビジュアルモードで選択後
:'<,'>normal @a         " 選択範囲の各行に独立してマクロを実行
                        " エラーが起きた行はスキップして次の行へ継続

" :g と組み合わせる場合（パターン一致行だけに並列適用）
:g/pattern/normal @a    " パターン一致行それぞれにマクロを実行
```

---

## マクロのコマンドライン実行

```vim
:normal @a              " 現在行にマクロを実行
:10,20normal @a         " 10〜20行目にマクロを実行
:.,+5normal @a          " 現在行から5行下までにマクロを実行
```

## マクロのデバッグと編集

```vim
" レジスタの内容確認
:reg a          " aレジスタの内容を表示

" テキストとして編集
:new            " 新しいバッファを開く
"ap             " aレジスタの内容を貼り付け
"ayy            " 編集後にaレジスタへ保存し直す
:q!             " バッファを閉じる

" レジスタを直接操作
:let @a = ''    " aレジスタを空にする（再帰マクロの前に使う）
```

## 設定ファイルへの保存（init.vim / .vimrc）

```vim
" 行末にセミコロンを追加して次の行へ
let @q = 'A;<Esc>j'

" 行頭に # コメントを追加して次の行へ
let @c = 'I# <Esc>j'

" 行頭に // コメントを追加して次の行へ（JS/C系）
let @j = 'I// <Esc>j'

" 特殊キーの書き方
" Escapeキー  → <Esc>
" Enterキー   → <CR>
" Ctrl+R      → <C-r>
" Ctrl+A      → <C-a>（数値インクリメント）
```

## Neovim（Lua）での設定（init.lua）

```lua
-- vim.fn.setreg() でレジスタに値をセット
vim.fn.setreg('q', 'A;<ESC>j')   -- 行末にセミコロン追加
vim.fn.setreg('c', 'I# <ESC>j')  -- 行頭に # コメント追加
vim.fn.setreg('j', 'I// <ESC>j') -- 行頭に // コメント追加

-- マクロの内容（キー操作）自体はVimScriptと同じ
-- 設定ファイルの書き方が違うだけで、@q での実行方法は変わらない
```

## VimScript（マクロの限界を超えたいとき）

```vim
" 関数の定義
function! NumberLines()
    let n = 1
    for lnum in range(1, line('$'))
        call setline(lnum, n . '. ' . getline(lnum))
        let n += 1
    endfor
endfunction

" 実行
:call NumberLines()
```

マクロ → VimScript の順で覚えると、段階的にVimの力を引き出せる。

## よく使うマクロテンプレート

```vim
" 行末にセミコロン追加
let @s = 'A;<Esc>j'

" 行末にカンマ追加
let @m = 'A,<Esc>j'

" 行頭に - （箇条書き）追加
let @b = 'I- <Esc>j'

" <p>タグで囲む
let @p = 'I<p><Esc>A</p><Esc>j'
```
