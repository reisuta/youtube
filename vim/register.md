# Vimレジスタ - コマンドリファレンス

## レジスタ一覧の表示

```vim
:reg
:reg a      " aレジスタのみ表示
:reg 0 a b  " 0, a, bレジスタを表示
```

## レジスタを指定してヤンク

```vim
"ayy    " aレジスタに現在行をヤンク
"ayw    " aレジスタに単語をヤンク
"ay$    " aレジスタに行末までヤンク
```

## レジスタを指定してペースト

```vim
"ap     " aレジスタの内容をカーソルの後ろにペースト
"aP     " aレジスタの内容をカーソルの前にペースト
"0p     " ヤンクレジスタ(0番)の内容をペースト
"+p     " システムクリップボードからペースト
```

## レジスタへの削除（カット）

```vim
"add    " aレジスタに行を削除（カット）
"adw    " aレジスタに単語を削除（カット）
"_dd    " ブラックホールレジスタに削除（レジスタを汚さない）
"_dw    " ブラックホールレジスタに単語を削除
```

## 大文字レジスタ（追記モード）

```vim
"Ayy    " aレジスタに現在行を追記
"Ayw    " aレジスタに単語を追記
```

## Insert modeでのレジスタ挿入

```vim
<C-r>a      " aレジスタの内容を挿入
<C-r>0      " ヤンクレジスタの内容を挿入
<C-r>+      " システムクリップボードの内容を挿入
<C-r>=      " エクスプレッションレジスタ（計算式を入力して結果を挿入）
```

## 特殊レジスタの参照

```vim
"%p         " 現在のファイル名をペースト
":p         " 最後に実行したコマンドをペースト
".p         " 最後に挿入したテキストをペースト
"/p         " 最後の検索パターンをペースト
```

## システムクリップボードと統合（init.vim / .vimrc）

```vim
" yy や p が自動的にシステムクリップボードと連携
set clipboard=unnamedplus
set clipboard=unnamed
```

## レジスタをリセットする

```vim
:let @a = ''    " aレジスタを空にする
:let @+ = ''    " システムクリップボードを空にする
:let @" = ''    " 無名レジスタを空にする
```

## よく使うレジスタ一覧

| レジスタ | 名前 | 説明 |
|---------|------|------|
| `""` | 無名レジスタ | デフォルト（最後に使ったレジスタを指す） |
| `"0` | ヤンクレジスタ | yコマンド専用（deleteで上書きされない） |
| `"1`〜`"9` | 番号付きレジスタ | 削除履歴（1=最新〜9=最古） |
| `"a`〜`"z` | 名前付きレジスタ | ユーザー専用（小文字=上書き、大文字=追記） |
| `"-` | 小削除レジスタ | 1行未満の削除 |
| `"_` | ブラックホールレジスタ | 完全削除（他のレジスタを汚さない） |
| `"+` | システムクリップボード | OS連携（Linux） |
| `"*` | 選択範囲レジスタ | X11プライマリ / macOSクリップボード |
| `":` | コマンドラインレジスタ | 最後のコマンド（読み取り専用） |
| `".` | 挿入テキストレジスタ | 最後に挿入したテキスト（読み取り専用） |
| `"%` | ファイル名レジスタ | 現在のファイル名（読み取り専用） |
| `"/` | 検索パターンレジスタ | 最後の検索パターン（読み取り専用） |
| `"=` | Expressionレジスタ | 計算・関数の結果を挿入 |
